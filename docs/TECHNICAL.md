# Plasmo Musicshare 1.2.19

## 全局抓取与指定程序

在“音乐共享”页提供“只抓取指定程序”“选择程序”和独立的“扫描程序”按钮。默认保留全局抓取：分享除当前 Minecraft 进程树之外的声音。程序列表仅按“扫描程序”手动更新；开启共享、试听、打开选择页和应用选择均不会自动刷新列表。新启动的其他程序需要手动扫描后才能列出。

开启“只抓取指定程序”，点击“选择程序”，搜索并勾选一个或多个程序，然后点击“应用”。列表按可执行文件路径归组，显示进程数量，同名不同目录的程序分别列出；已保存但暂未运行的程序仍可查看和取消选择。点击模式按钮可切回全局抓取，取消按钮不会应用页面中的草稿选择。独立 /music 页面也有选择入口。

指定模式仅采集选定程序及其子进程，多程序音频混合后再进入原有音乐通道；未选中 KOOK 时不分享独立 KOOK 程序的声音。父子进程一起勾选时自动去重。播放器重启后按已保存的可执行文件路径重新识别；没有选择程序或目标未运行时保持静音，不会退回全局抓取。当前 Minecraft、它的子进程和会把 Minecraft 包含进来的祖先进程不允许成为采集根。

程序选择保存于 config/plasmo-musicshare-capture.properties。正常抓取时只检查所选进程的身份，不反复枚举全部程序。仅在所选程序未运行、退出或重启时，为恢复音源做后台检查，间隔从 5 秒逐步退避至 30 秒；找到目标后停止枚举，后台恢复不刷新界面列表。空选择与全局模式不会触发这种恢复扫描。扫描只读取可执行文件身份、PID、父子关系和启动时间，不读取命令行参数或环境变量。Windows 权限可能使某些受保护程序无法列出或采集；程序音频启动失败时会重试并写日志。浏览器按程序及进程树采集，无法区分同一个浏览器里的音乐网页和 KOOK 网页；此场景需要使用不同的浏览器程序或独立 KOOK 客户端。

1.2.19：继续使用内置 TarsosDSP，不加入 AI 引擎。删除婴儿声与极阴老祖预设，替换为小孩与反派，新增水下低通。机器人放宽滤波频段，并为变调、机器人及水下预设加入有上限的平滑 RMS 电平补偿，减少变声后突然变小。补偿发生在回声与混响前，静音不生成声音，尾音自然衰减；音乐、麦克风门限和图标检测保持原样。程序列表手动扫描、后台进程恢复、诊断写盘优化均保留。

本版将音乐发送音量从 0～150% 扩展为 0～500%（最大 5 倍），原有默认值和保存的音量保留。可以降低播放器自己的音量，再用发送音量补偿共享音乐的响度；播放器静音时无法放大出音乐。过高增益会触及 PCM 限幅并产生失真，建议从较低值逐步调高。该增益只处理共享音乐，人声的增益仍由 Plasmo Voice 控制；若本机试听包含音乐，也会听到放大后的音乐。

Windows 客户端附属模组：Fabric Minecraft 1.21.11、Plasmo Voice 2.x（最低 2.1.17），可选 Talking Heads 1.1.3。TarsosDSP core 2.5 已直接内置，无需额外安装 TarsosDSP、Soundboard 或 soundboard-core。

## Plasmo Voice 更新兼容

1.2.15 不再锁死 Plasmo Voice 的单个版本号，允许 2.1.17 及以上的 2.x 版本。已针对 2.1.17 和 2.2.0-beta.1 验证；同一份 JAR 可以搭配这两个版本。2.2 的玩家图标方法将参数从 LivingEntity 扩展为 Entity，本版同时支持两种签名。

加载前会检查采集、编码与结束发包方法、试听注入位置、设置页以及本地玩家图标接口，并检查本模组直接使用的 Plasmo Voice/config/slib 类型和方法引用。检查通过才启用全部注入和附属功能；发现已覆盖的接口或注入位置变化时，停用 Musicshare、保留原生 Plasmo Voice，并在日志与进入世界后的聊天中提示原因。不会仅凭版本号大小猜测接口兼容。

结构检查无法判断接口内部行为变化，也不能保证与未来所有版本或其他模组兼容。Minecraft 版本仍限定为 1.21.11，Plasmo Voice 3.x 仍需单独适配。升级后出现异常时请提供日志。

## 使用

手动替换旧 Plasmo Musicshare JAR，不要同时加载两个版本。保留 Fabric API 和 Plasmo Voice。开发和发布文件位于独立工作目录，未改动用户游戏 mods/config 文件夹。

音乐共享快捷键按一次开音乐共享，再按一次关闭。人声屏蔽快捷键按住开启人声屏蔽，松开恢复；按键重复不会反复切换。界面内所有按键提示统一显示“快捷键”，实际默认绑定保持不变，可在游戏控制设置重新绑定。Plasmo Voice 继续控制麦克风设备、输出设备、按键说话/语音激活、服务器静音、权限和附近距离。/music、/music on、/music off、/music status 保留。界面手动屏蔽开关仍可用于测试。

## 强制话筒开启

在 Plasmo Voice 的“音乐共享”页增加“强制话筒开启”开关，默认关闭，选择会保存。开启音乐共享时，强制模式允许低于感应阈值的共享音频继续发送，包括静音帧，避免轻音乐被门限打断；关闭该选项后恢复原来的发送门限。

此开关维持音乐共享发送流，真人麦克风仍遵循 Plasmo Voice 的语音激活/按键说话规则，不会混入尚未激活的人声；服务器静音、禁用麦克风、权限和附近距离继续有效。本机 HUD、头顶喇叭和 Talking Heads 仍按感应阈值显示。因为强制模式持续发送，远端玩家的小喇叭可能常亮。不开音乐共享时，该选项不产生发送。

此前的修复保留：清除音效旁路/重新启用时的旧人声队列，避免回放残留回声；试听设备采样率暂时无效时清空延迟缓冲，恢复有效格式后重新累积。
## 音乐音效页：TarsosDSP 人声操作面板

该页名称为“音乐音效”，但新 DSP 面板只作用于人声，不处理音乐。已有独立双通道唱歌混响仍放在同一页；音乐共享和本机试听各有单独页面。音乐发送音量和立体声保留。此前移除的六种风格和旧音乐变调等效果不恢复。

可独立设置与组合：

| 效果 | 参数 |
| --- | --- |
| 镶边 | 开关、混合量 0～100%、扫动速率 0.1～3 Hz、深度 1～15 ms |
| 延迟/回声 | 开关、间隔 100～800 ms、反馈 5～65%、回声音量 0～250% |
| 变调 | -12～+12 半音，0 为旁路 |
| 滤波 | 关闭、低通、高通、带通；截止/中心频率 100～12000 Hz |
| 时间拉伸 | 开关、语速 75～150%，100% 为旁路，使用 WSOLA 保持音调 |
| 特殊模式 | 机器人载波、原声直通＋厚重后置回声 |

预设下拉框提供原声、回声、机器人声、小孩、反派、水下低通、自定义。选择命名预设会填入面板参数，并将回声间隔/反馈恢复到 320 ms/40%；手动修改 DSP 参数后显示自定义。选择原声清空面板效果，保留独立混响、共享和试听设置。总强度 0% 为原声、100% 使用完整面板效果。默认原声旁路。

- 回声：原声加衰减重复。
- 机器人声：环形调制加少量镶边与宽范围低通，自动补偿输出电平；不再使用容易削掉低音人声的窄带滤波。
- 小孩：提高 4 半音，轻度柔化高频，自动补偿变调损失。是声音特效，不是 AI 声音克隆。
- 反派：直接人声降低 5 半音，4500 Hz 低通，随后加入默认 55% 的低沉回响。替换原先仅后置低声的老祖预设。
- 水下低通：650 Hz 低通，压住高频形成闷沉音色，同时补偿平均电平。截止频率可在面板调整，修改后显示自定义。

响度补偿采用每声道独立的平滑 RMS 跟随，增益有上下限，不把静音变成声音。目标是接近原声平均电平；不同音色的主观响度仍可能不同，过大的输入会触及 PCM 限幅。原声旁路保持逐样本直通，单独使用自定义滤波仍保留滤波衰减。

镶边有约 5 ms 的分块延迟，变调有几十毫秒窗口延迟。修改处理参数会清空该处理器旧状态，按住 人声屏蔽快捷键 屏蔽时同样清除人声预设和人声混响尾音，音乐不受屏蔽影响。

## 实时时间拉伸的限制

实时麦克风仍以固定采样率和网络帧长度发送。减速生成更多音频，缓冲上限为 0.5 秒；达到上限会跳过部分旧片段并短暂平滑衔接。加速生成更少音频，可能出现空隙。这是实验性实时语速效果，适合短句试玩，不保证长时间连续讲话仍完整保留所有字音。100% 或关闭时完全旁路，不引入拉伸缓冲。更改参数、人声屏蔽快捷键 屏蔽、断开连接时不保留旧人声队列。

## 混响、试听与显示

已有独立人声/音乐混响保留小房间、录音棚、舞台、大厅预设，默认关闭。麦克风正常停止后允许已有回声和混响衰减，服务器静音与禁用继续阻止发送。

“本机试听”复用 Plasmo Voice 原生输出设备与试听控制器，延迟为无延迟、1～10 秒，默认 1 秒；可调试听音量并选择是否包含音乐。只延迟本机试听，不给网络音乐共享增加试听延迟。试听期间暂停对外发送，音乐共享开关保持不变；关闭试听或关闭整个 Plasmo Voice 设置后恢复。修改试听延迟、重新开启或设备格式变化清空旧缓冲。

本机 HUD、头顶喇叭和 Talking Heads 继续使用 Plasmo Voice 感应阈值。未开启强制模式时，共享期间低于同一门限时发送一次结束通知，不持续发送静音包，达到门限恢复；远端图标仍受网络和接收端缓冲影响。普通模式下，低于阈值的微弱音乐不会对外播放；强制模式持续发送。屏蔽时保留原始人声检测，达到阈值播放内置 bi 音，不识别脏话语义。

音乐音源为 Windows 应用声音，可全局排除当前 Minecraft 或只包含所选程序树；不提供耳机设备回录选项。需要 Windows 11 或 Windows build 20348 及以上。多耳机时在 Plasmo Voice 中选好试听输出设备；播放器仍从它自己的输出设备直接播放。

配置继续使用 config/plasmo-musicshare-studio.properties，使用 schema 4。schema 2/3 保存的婴儿与老祖预设自动转为小孩与反派，并填入新参数，混响与试听设置保留；已有自定义 DSP 参数保留，包含此前自行设置的后置回声开关。更早的已删除风格不恢复。
